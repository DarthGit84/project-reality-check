# Changelog

All notable user-visible changes to Project Reality Check are documented here.

## 0.1.0 — 2026-09-08

Initial public release.

- Research-first evidence ledger with exact claim labels.
- Constructive red-team review that preserves substantiated elements.
- Human-owned recommendation and decision boundary.
- Optional independent reviewer/subagent, requiring explicit consent.
- Status hierarchy that exposes blocked evidence.
- Rework handoff template for material corrections.
- Six behavior-based evaluation scenarios.
